## Context

44 Used Cases are defined, they correspond to very specific scenario's (soon 45). Check that some of those cases might be relevant to you as a sender.

If certain used cases might be applicabel to you, study them in detail first.

For certain used cases, additional information must be included in the e-invoice message.

When certain used cases might be applicable to you, you can report this to Billit. Billit will informa you about the status.
