# Sandbox VS Production\n\nBillit provides two distinct environments tailored for developers. The first environment is linked directly to all production accounting data and e-invoice networks, enabling real-world data processing and communication. The second environment is a replica of the production setup, designed for testing purposes. By utilizing test networks, developers can ensure that their data does not get transmitted to government entities or e-invoice networks inadvertently, offering a secure sandbox for development and experimentation.

You can find more info here [Sandbox VS Production](https://docs.billit.be/docs/sandbox-vs-production)
