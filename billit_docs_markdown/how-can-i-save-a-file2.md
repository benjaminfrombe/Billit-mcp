## Is Including an Attachment Mandatory / Recommended ?

When you send via einvoicing networks such as Open/Peppol, what about the attachments ?

- Attachments are not mandatory
- Attachments types can be :
  - PDF of the invoice: a human readable version of the invoice allows the receiver to understand the content
  - Other Attachments can give additional information (e.g. calculation of costs, Proof of Delivery, ...)

## Does Billit always send an attachment when sending in an e-invoice network?

Yes :

- If Sender includes a PDF as an invoice attachment, then this will be sent. Billit will not generate a human readable.
- If Sender does not include a PDF, then Billit will generate the PDF and include it in the delivery.

## Billit is Generating a PDF, can it be edited ?

Yes. For more details see [https://docs.billit.be/docs/billit-generated-pdf](billit-generated-pdf.md)

## Supported Attachment file types

Types:

- Role of the attachment
  - The main invoice attachment (Your PDF or Billit Generated PDF)
  - Other attachments : any other attachment (multiple attachments are allowed)
- The file type of the attachment, allowed attachments when sending via Open/Peppol:
  - PDF
  - Excel
  - csv
  - Image JPEG, Image PNG
- What wen you want to send other file attachment types ?
  - convert the file attachment to PDF
