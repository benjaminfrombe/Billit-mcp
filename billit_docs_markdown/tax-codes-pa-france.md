## Ventilation Codes to Use for France

For General use of ventilation codes, see [https://docs.billit.be/docs/ventilation-codes](ventilation-codes.md) .

**Domestic overview**

For tax percentages below, Ventilation codes do not have to be included:

| Tax Percentage | Billit Ventilation Code (optional) |
| --- | --- |
| 20 % | 4 |
| 10 % | 3 |
| 5,5 % | 2 |
| 0 % | 1 |

**Specific French codes for 0 %, exempt and related:**

| Description | Billit Ventilation Code | UBL TaxCategory ID |
| --- | --- | --- |
| Miscelaneous non-VAT | 22 | O |
| IC of goods | 51 | K |
| IC Services | 55 | K |
| OSS | 104 | E |
