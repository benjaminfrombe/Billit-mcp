# How do I request a demo for my integration?

Nice, you want to demo what you built.

Before we can go to the demo phase, please check these requirements before planning the meeting.

❓ Is it working as expected on Sandbox?

❓ Are you able to demo a working flow?

# Accreditation Process

1. Create a **Production** Account ( [Direct Link](https://my.billit.be/Account/Register?Language=EN))
2. Click on **Profile** icon (top right corner) and Select **Developers** ( [Direct Link](https://my.billit.eu/Developer/DeveloperDashboard))
3. Use the **Create Integration** action in the top right corner
4. Select one of the following options
1. **ERP software** wanting to add e-invoice sending and/or receiving capabiltities for your customers
2. Getting your **own software** compliant
3. You are a developer and you want to setup your own **private connection**
4. You want an **App** available in the integrations page for all Billit users
5. Provide the **Name** for the integration
6. Select the **Country**
7. Specify the **capabilities**
1. Sending
2. Receiving
3. Sending & Receiving
4. None
8. Select the preferred **Integration** method

1. API
2. SFTP
3. E-Mail
4. Manual
9. The integration (app) is now created, please click on **Detail**
1. Provide the Sandbox Company ID
      1. You can find the CompanyID by opening your SandBox account and clicking on My Company (left menu). In the URL there you can find the CompanyID.
2. Review the Documentation & Development steps
3. Provide a demo video
4. Request App Review
5. Sign Agreements
