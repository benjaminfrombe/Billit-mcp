## What Line Information Elements are present on the Template

| By Default Present on Template | Can be added to template |
| --- | --- |
| Quantity | DescriptionExtended |
| UnitPriceExcl | Reference |
| Description |  |
| VATPercentage |  |
| Linetotals (calculated) |  |
| Discount percentage |  |

Other elements cannot be added. If you want to get it on the template, copy the information in the field "Description Extended", a maximum length of 512 characters can be used without any problem.
