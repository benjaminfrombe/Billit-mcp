## Create Support Ticket from My Billit User Interface

The best way to create a case for Billit support is via the My Billit interface in the **production** environment (not sandbox).

Click on the help button:

![](https://files.readme.io/27901dbac68d5762db7440c76d6b22f7bc66afcb85c5359ba8dee6f7b75fc63f-Schermafbeelding_2025-11-24_095323.png)

You can fill in the data. Some special elements:

- you can give it a category (allows better dispatching at Billit)
- Billit has automatically you contact details and company info
- You can give access to billit for a limited period (not mandatory)
- files can be uploaded (PDF, images). You can send Json or XML files later via email, convert to txt extension (not json or xml).
- you can make screenshot from your screen
