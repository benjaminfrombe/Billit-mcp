## API overview and support for PA France

The use of the API allows to support a maximum number of scenario's.

Info about type of API that is supported:

| Type of API | Supported for PA | Extra Info |
| --- | --- | --- |
| v1/order | yes | Recommended endpoint for general use |
| v1/einvoice | yes | You must be allowed and whitelisted for this endpoint |
| v1/peppol | no | Cannot be used for the French network |

## Use without API

Alternatives are the upload of UBL files.

Documentation will be published about constraints (espcialally for the advanced scenario's).
