### GET Command of the Files

| Endpoint | Method | Response | Extra Info |
| --- | --- | --- | --- |
| /v1/files/FileID | GET | 1 file | Includes full data and file references |

### Reference and Content of the Files

The FileID is the unique Reference.

Below Examples:

- Example 1 returns the minimum (2 files)
  - OrderPDF : this PDF is file delivered by the supplier (if existing), otherwise it is a PDF generated by Billit
  - Attachments :
    - one attachment, it is the UBL/XML file generated by Billit when receiving the data. This XML can be very helpful when you want to store the file in your own environment or if you want the process it.
    - When received via Peppol, the Peppol XML should always be available.
      - If it is not available : check that :
        - Document is not stopped in Fast Input
        - Approval in MyBillit portal might still be ongoing
- Example 2 (6 files)
  - OrderPDF : this PDF is file delivered by the supplier (if existing), otherwise it is a PDF generated by Billit
  - Attachments : 1 XML (the UBL), 3 PDF files, 1 Excel
