# Get Files\n\n### GET Command of the Files   [Skip link to GET Command of the Files](https://docs.billit.be/docs/get-files\#get-command-of-the-files)

| Endpoint | Method | Response | Extra Info |
| --- | --- | --- | --- |
| /v1/files/FileID | GET | 1 file | Includes full data and file references |

### Reference and Content of the Files   [Skip link to Reference and Content of the Files](https://docs.billit.be/docs/get-files\#reference-and-content-of-the-files)

The FileID is the unique Reference.

Below 2 Examples:

- Example 1 returns the minimum
  - OrderPDF : this PDF is file delivered by the supplier (if existing), otherwise it is a PDF generated by Billit
  - Attachments : one attachment, it is the XML file generated by Billit when receiving the data
