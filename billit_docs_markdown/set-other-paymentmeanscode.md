# Set other PaymentMeansCode

When sending invoices via the Peppol network, the PaymentMeansCode is set automatically by Billit.

If you want the define another PaymentMeanscode, this can be set by the CustomField "PaymentMeansCode".

For the list of all PaymentMeansCodes, we refer to the Peppol list: [https://docs.peppol.eu/poacc/billing/3.0/codelist/UNCL4461/](https://docs.peppol.eu/poacc/billing/3.0/codelist/UNCL4461/)
