# API QuickStart Sending Invoices\n\nWelcome to the Billit API QuickStart Guide! This guide provides you with simple examples to get you up and running with our API. Whether you're using Postman, curl, or any other API testing tool, these examples will help you make your first API calls.

## Prerequisites   [Skip link to Prerequisites](https://docs.billit.be/docs/quick-start\#prerequisites)

before you start, make sure you have:

- A Billit sandbox Account. You can register an account make it directly active. Any license can be taken, no invoice will be sent for the sandbox.
- The generated API key (found under your profile in the Billit application)

![](https://files.readme.io/a7a513756f4e63033bd484ed1c056ed5db4b009226a55bb916fae9382273a270-afbeelding.png)

- The PartyID (found in the URL):

![](https://files.readme.io/3d091e5c8ba41337853460679cef17cb8facbb810b4d0c2e6ac15cb10b0d865d-afbeelding.png)

- The base URL used for all API calls: For sandbox this is : ["https://api.sandbox.billit.be"](https://docs.billit.be/docs/quick-start)
- Installed Postman or a similar tool for making API request for starting your first tests.

**Authentication**

For this sandbox quick start walkthrough the API key authentication will be used. This to have fast results!
