## What is Needed to be able to send via Billit ?

In order to send, this is what is needed:

- [x]  Create you account in Billit
- [x]  Make sure that data are filled, info : [https://docs.billit.be/docs/basic-data](basic-data.md)

You can then start sending. Sending via API : [https://docs.billit.be/docs/create-first-invoice](creating-sales-invoices.md)

## What if Peppol Receiving is done via Another Access Point ?

In order to send via the Open/Peppol network, you do not have to be registered on the Open/Peppol network, as this registration is for receiving of documents, not for sending of documents.

This is why it is perfectly possible that the Peppol registration for receiving is done via another Acces Point.

You are still able to check:

- The successful delivery of the file to Peppol.
- To view the evidence file of this successful delivery.
- More info : [https://docs.billit.be/docs/status-content-of-a-sales-invoice](status-content-of-a-sales-invoice.md).
