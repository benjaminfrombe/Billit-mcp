# Discounts, Charges

2 Methods are available:

- Simple :
  - Commercial and financial discounts can easily be included using Billit Json fields.
  - In the output file Billit generates the complete content in a valid way.
  - This is easy to use.
  - Limitation : No support for other scenario's such as charges or header discounts other then financial discount.
  - This is explained in the first section.
- All scenario's:
  - Fill in your own allowance (discount) and charge information.
  - This is explained in the second section.
