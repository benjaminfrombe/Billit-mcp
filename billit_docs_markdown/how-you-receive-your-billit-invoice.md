# How you receive your Invoices from Billit

1. **Receive via Open/Peppol**

When you are able to receive invoices via the Peppol production environment, then Billit automatically sends the invoice for Billit licences via O **pen/Peppol**, and not via email.

2. **Other Receiving : Email**

When Peppol receiving is not possible, the invoices for the Billit licence is sent via email.
