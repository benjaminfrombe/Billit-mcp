# 500\n\nAt Billit we do not want the end user to experience 500 Errors, This means we did not handle the exception or validation correct. Please contact support with the API call that caused this error. Also try and describe what the use case of the call is.

> ## 🚧  Never Share
>
> Please do not send us your API key or credentials in the support ticket! Billit support will never ask for secret keys!
