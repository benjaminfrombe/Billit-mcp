## Options

When the person who must do the identification (legal representative) is not yet a user at Billit, then there are 2 options:

- Method 1 : launch activation from MyCompany screen
- Method 2 : an additional user must be created. If needed, after identification, the user can be deactivated (no extra costs for user).

## Method 1 : Launch Verification from MyBillit User Interface

This method is available since 17/12/2025.

Go to My Company, Company:

![](https://files.readme.io/530c4b2c779377a7857281e9f9333f2e6365b80ade9237c338e955a819105847-2025-12-17_13-21-10.png)

And launch the pop-up screen via the Verify button:

![](https://files.readme.io/f5a09d2ec7394ec16a3f2a378a8a36c9634b7fe07c7b3351ff7edaf4354a48e4-2025-12-17_13-24-03.png)

Options:

1. Verify via Itsme : barcode or phone number allow to launch verification for the legal representative
2. Copy itsme link : a link that can be included in a message to the legal representative

## Method 2 : Create and Activate the User

In Settings, Users, start User Creation:

![](https://files.readme.io/823af6d57b8c78599026b1a2f38ca3f02926ef36da30083c379bd03d1561399d-2025-11-14_14-19-28.png)

A confirmation will be displayed that process is initated

Link request sent to user: [firstname.testuser@company.com](https://docs.billit.be/docs/firstname.testuser@company.com)

Link:

![](https://files.readme.io/38ebb2b91e35f2d0e1fce59d72644c021b3195afe5e3dec1847443304a8f1ba0-2025-11-14_14-22-34.png)

Forget password:

![](https://files.readme.io/5a25d25fa1c2e49b1ec329586742aa3530c107ea41a8385499073d71d9575e62-2025-11-14_14-23-35.png)

Confirmation forget password:

![](https://files.readme.io/38d044788cfbb17046985d83c76e8aae2d9e991b6d910eaf31dfa5a839a4243c-2025-11-14_14-24-25.png)

Fill in new password and confirm

![](https://files.readme.io/01f42f8c8b40e2584f4d1bcf407976b09cd2c0da24ec5526d4b4eda351f635fc-2025-11-14_14-25-30.png)

Confirm Linking to the company. No obligation to confirm mobile number or activate MFA:

![](https://files.readme.io/65de729d4ebc951b82b2a019c724ef3aa92219f118239216561bb331862a3ad4-2025-12-17_13-28-29.png)

The user is now active. Perform the identity validation.

## Verification Termined - deactivate User

When the verification is terminated, you might not be required any more to keep the user active. You can then go to the Settings / Users and deactivate this user. When the user is deactivated the same day, no licence cost is charged.
