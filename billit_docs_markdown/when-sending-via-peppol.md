# When sending via Peppol DE

- Make sure that your customer is on Peppol.
  - How to verify : [https://docs.billit.be/docs/how-do-i-know-who-is-a-peppol-receiver](who-is-a-einvoice-receiver.md)
  - Keep in mind the identifiers for Germany: [https://docs.billit.be/docs/identfiers](identifiers.md)
- The customer might have registered specific formats and versions as supported document types.
  - Most common will we Xrechnung variants and maybe standard Peppol and CII formats
  - You do not have to specify it
  - Billit will convert to an allowed format when supported by Billit.
