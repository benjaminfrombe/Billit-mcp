# Non API methods for Export

In addition extracting received supplier invoices via API, alternative solutions are available:

- Export invoices via email using BillMail
  - Email with PDF
  - Email with XML (attached PDF in the the XML)
- Export invoices to sFTP server
  - More info : [https://docs.billit.be/docs/sftp-example-for-purchase-invoices](sftp-example-for-purchase-invoices.md)
