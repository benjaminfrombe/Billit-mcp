## No Receiving via Billit

When you are receiving Invoices from Peppol via the Billit Access Point, and you do not want this, then this can be deactivated.

Practically:

- You can do this yourself via the My Billit Platform
- Needs to be done for each company
- Can be performed on the environments sandbox and production
- Result is a deregistration on Peppol
- On API level, you do not have to change something

## How can I see in My Billit interface that I am registered for Receiving

When screen in My Company / E-invoicing is green, you are registered as a receiver:
