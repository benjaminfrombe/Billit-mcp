# Check Validity of UBL file

When you are posting UBL files via API, one of the requirements is that your UBL file is valid. This can be verified prior to posting to Billit.

Tool that can be used is [https://ecosio.com/en/peppol-e-invoice-xml-document-validator/](https://ecosio.com/en/peppol-e-invoice-xml-document-validator/)
